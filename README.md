## Управление и правила

- WASD перемещают курьера. Поддерживается русская раскладка.
- Шаг расходует 1 энергию, вход на ловушку расходует 5. Стена останавливает курьера без расхода энергии.
- Обычная доставка приносит 10 очков, срочная приносит 25.
- Батарейка восстанавливает до 8 энергии в пределах максимума этажа.
- B покупает ускорение за 5 очков. Следующие три команды движения делают до двух шагов. Каждый шаг расходует энергию и обрабатывает клетку.
- Счётчик ходов учитывает успешные шаги.
- При нулевой энергии попытка заканчивается. R начинает новую игру после проигрыша. Q закрывает игру.
- После всех доставок вернитесь к лифту для перехода на следующий этаж.

## Структура репозитория

| Файл | Назначение |
| level.py | Карта, стены, ловушки, батарейки, доставки и проверка проходимости |
| game.py | Состояние игры, движение, энергия, награды, ускорение и счётчик шагов |
| main.py | Запуск в терминале, ввод и вывод карты |
| window.py | Графическое окно, управление и отрисовка |
| courier.png | Фото курьера |
