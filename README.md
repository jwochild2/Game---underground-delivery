# Подземная доставка

Игра на Python о курьере в подземном комплексе. Нужно доставить все посылки на этаже и вернуться к лифту. Следующий этаж создаётся случайно и становится сложнее.

## Запуск

Скачайте репозиторий через Code → Download ZIP и распакуйте архив. Откройте папку проекта в Терминале.

Для версии с фотографией выполните:

```sh
python3 window.py
```

Для терминальной версии выполните:

```sh
python3 main.py
```

В Windows можно использовать `py` вместо `python3`. Нужен Python 3.10 или новее. Графическое окно использует Tkinter. Файл courier.png должен лежать рядом с window.py.

## Управление и правила

- WASD перемещают курьера. Поддерживается русская раскладка.
- Шаг расходует 1 энергию, вход на ловушку расходует 5. Стена останавливает курьера без расхода энергии.
- Обычная доставка приносит 10 очков, срочная приносит 25.
- Батарейка восстанавливает до 8 энергии в пределах максимума этажа.
- B покупает ускорение за 5 очков. Следующие три команды движения делают до двух шагов. Каждый шаг расходует энергию и обрабатывает клетку.
- Счётчик ходов учитывает успешные шаги.
- При нулевой энергии попытка заканчивается. R начинает новую игру после проигрыша. Q закрывает игру.
- После всех доставок вернитесь к лифту для перехода на следующий этаж.

## Структура репозитория

| Файл | Назначение |
| --- | --- |
| level.py | Карта, стены, ловушки, батарейки, доставки и проверка проходимости |
| game.py | Состояние игры, движение, энергия, награды, ускорение и счётчик шагов |
| main.py | Запуск в терминале, ввод и вывод карты |

Для графической версии используется window.py. Файл window (1).py сохранился от предыдущей загрузки и не участвует в этом запуске.

## Что объяснить на защите

Карта хранится в объекте Level. Метод Game.move принимает направление и вызывает обработку каждого шага. Шаг проверяет стену, меняет координаты, расходует энергию и обрабатывает объект клетки. Окно после команды перерисовывает карту.

Декоратор count_moves считает перемещения. Замыкание create_energy_bonus запоминает восстановление батарейки. Свойство energy ограничивает запас энергии. Собственное исключение NotEnoughPoints сообщает о нехватке очков для ускорения. Рекурсия в level.py проверяет связность карты.
